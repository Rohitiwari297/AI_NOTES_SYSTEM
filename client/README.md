# AI Notes Management - Client (Frontend)

React + Vite frontend for the AI-Powered Notes Management System.

### ✨ Features
- **Notes List Display**: Clean grid view of all notes with category badge and tags.
- **Create Note**: Title, content, category, and tags.
- **Edit Note**: Pre-populated modal to update any note.
- **Delete Note**: 1-click delete with confirmation.
- **Search Functionality**: Real-time debounced keyword search.
- **AI Summary**: 1-click "Generate AI Summary" button on note cards.
- **Authentication**: Seamless Login & Register with JWT token storage.

---

### 🚀 Running the Client

1. **Install dependencies:**
   ```bash
   cd client
   npm install
   ```

2. **Start Development Server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.
